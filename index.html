    Help & FAQ

    Learn how to make the most of your task list.

    How do I add a task?

    Type a task into the input box and select Add task. Give each task a short, clear name.

    How do I complete a task?

    Check the box next to a task. You can uncheck it if you need to work on it again.

    How do I delete a task?

    Select Delete next to the task you want to remove.

    How do I clear completed tasks?

    Select Clear completed to remove all checked tasks at once.

    Are my tasks saved?

    Tasks are stored in this browser when local storage is available. Avoid entering personal or sensitive information in this usability testing demo.
